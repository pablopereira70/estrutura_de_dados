# 📊 Estrutura de dados 

Repositório dedicado ao armazenamento das resoluções da disciplina de estrutura de dados.

## 🧰 Tecnologias e ferramentas

- **Linguagem base:** C/C++
- **Ambiente de desenvolvimento:** VS Code
- **Documentação:** markdown `(.md)`

## 📂 Organização do repositório
O projeto está dividido em dois tipos de pastas.
- **`cap_*`** -> exercícios derivados de capítulos do livro.
- **`extras`** -> exercícios de materiais extras.

## 🎯 Competências Desenvolvidas

- **Estruturas lineares:** listas, pilhas e filas
- **Gerenciamento de memória:** ponteiros e alocação dinâmica em C/C++
- **Algoritmos de busca e ordenação**
- **Análise de complexidade:** noções de tempo e espaço (Big O)
